🗺️ ゲームの全体像

🔄 ゲームの基本ループ（中毒性の正体！）
この一周がスムーズに回るほど、プレイヤーは毎日戻ってくる
💰 お金を持つ → 🛒 種を買う → 🌱 畑に植える → ⏳ 育てる → ✨ 収穫 → 💴 売る → 💰 また買う…

制作ステップの流れ：

背景を作る → Shop設置 → 畑を作る → 家畜小屋を作る → GUI設置
→ 種購入システム → インベントリ → 種植えシステム → 育成システム → 収穫 → 売る

🔧 実践ステップ

STEP 1
背景を作る
✅ やること
Base のサイズを Studs で広げる。地面の Material を Grass に変える。Lighting → Atmosphere で空を朝っぽい柔らかい色に調整する。
⚠️ 注意点
背景を作り込みすぎると時間がなくなります。まずはざっくりでOK。雰囲気が出たら次へ進みましょう。
🔍 確認ポイント
「ここで農業をやりたい」と感じる世界観になっているか
STEP 2
Shopを設置する
✅ やること
Toolbox を開いて「Shop」と検索 → 農場っぽい建物を1つ選んでマップの端に置く → 位置とサイズを整える
⚠️ 注意点
この時点でコードや難しい設定は一切不要。あとでシステムをくっつけます。
🔍 確認ポイント
Shopがマップの端にあり、プレイヤーが近づきやすい配置になっているか
STEP 3
畑を作る
✅ やること
Part で土っぽい色の地面を作る（Material: SandStone または LeafyGrass）。 Toolbox で「Fence」と検索して柵を周りに配置する。
⚠️ 注意点
畑が広すぎるとシステム設置が大変に。プレイヤーが全体を見渡せるサイズが理想。
🔍 確認ポイント
畑エリアと外のエリアが柵で明確に区切られているか
STEP 4
家畜小屋を作る
✅ やること
Toolbox で「barn」または「Farm House」と検索 → 小屋を1つ持ってくる → Y軸で高さを調整して地面にめり込まないようにする → 畑の横に配置する
⚠️ 注意点
小屋の下に地面の Part を敷いておくと馴染みやすくなります。
🔍 確認ポイント
マップ全体が農場らしい雰囲気になっているか
STEP 5
GUIとインベントリを設置する
✅ やること
StarterGui → ScreenGui を作成 → Frame と TextButton を配置する。インベントリ用 Frame を画面左下あたりに置く。
⚠️ 注意点
見た目より機能を優先してシンプルに。デザインは後から整えられます。
🔍 確認ポイント
ゲームを起動したときに画面にGUIが表示されるか
STEP 6
種を買うシステムを作る
✅ やること
  1. Shop 前に Radar block（透明な Part） を置く
  2. Radar block を Invisible にして入口サイズに合わせる
  3. ゾーンに入ったらUIを表示・離れたら消えるスクリプトを書く
  4. 購入ボタンを押したら種のデータがプレイヤーに渡るようにする
⚠️ 注意点
Radar block の範囲が広すぎると遠くでもUIが出てしまいます。Shop の入口ぴったりに合わせましょう。
🔍 確認ポイント
Shopに近づいたらUIが出て、離れたら消えるか
STEP 7
インベントリに種を表示する
✅ やること
インベントリ Frame に種の名前と所持数を表示する。種を購入するたびにリストが更新されるようにする。
🔍 確認ポイント
種を買ったあとにインベントリに名前と数が表示されるか
STEP 8
種を植えるシステムを作る
✅ やること
  1. 畑の Part に Radar block を設置する
  2. 畑エリアに入ると種の名前がUIに表示される
  3. クリックしたら足元に茎（Part）が生成される
  4. UIから種の名前が消えてインベントリの所持数が1つ減る
  5. 植えた場所の座標を記録しておく（育成システムで使う！）
⚠️ 注意点
畑の外では種植えUIは出ないように設定しましょう。植えた座標の記録を忘れずに！
🔍 確認ポイント
畑エリアに入ったときだけUIが出るか。クリックで茎が生えてインベントリが減るか。
STEP 9
育成システムを作る（4段階）
✅ やること
  1. 植えた茎が時間経過で 4段階 に成長するスクリプトを書く
  2. 各段階でサイズ（Scale）が変わる
  3. 最終段階で キラキラのエフェクト が出る
⚠️ 注意点
テスト中は成長時間を短めに設定して動作確認。リリース前にちょうどよい時間に伸ばします。
🔍 確認ポイント
茎が段階的にサイズアップするか。最終段階でエフェクトが出るか。
STEP 10
収穫システムを作る
✅ やること
  1. 茎の Part に ClickDetector をくっつける
  2. クリックされたら茎が消えてインベントリに野菜が追加される
  3. 収穫した瞬間に画面に野菜名が表示される
  4. 一定時間放置したら自動で消えるスクリプトを追加する
⚠️ 注意点
放置消滅の処理を入れておかないと、畑がいっぱいになって後から収穫できなくなります。
🔍 確認ポイント
育ちきった茎をクリックで収穫できるか。長時間放置で自動消滅するか。
STEP 11
野菜を売るシステムを作る
✅ やること
  1. Shop 前に戻ると野菜を売るUIが表示される
  2. 野菜の名前・数量・値段が一覧で出てくる
  3. 売るボタンを押すとお金がもらえる
  4. 野菜ごとに値段を変えておく（レアな作物ほど高値に！）
🔍 確認ポイント
Shopに近づくと売るUIが出るか。売ったら野菜がなくなってお金が増えるか。一周サイクルが完成しているか。

⭐ 重要ポイント

⭐
ゲームループが中毒性の核心
「種を買う → 育てる → 収穫する → 売る」の一周がスムーズに回ることがプレイヤーをリピートさせます。Grow a Garden が100万人同時接続を達成したのもこのループが完成していたから。
⭐
Radar blockでゾーン検知
透明な Part（Radar block）を使って Shop や畑のエリアを検知し、UIを自動表示します。これがゾーンシステムの基本で、何度も使うテクニックです。
⭐
育成の4段階で視覚的フィードバック
サイズが段階的に変わることでプレイヤーは「育ってる！」を実感できます。最後のキラキラエフェクトが「収穫してください」のサインになります。
⭐
テスト中は成長時間を短く
動作確認のために成長時間はまず短めに設定し、リリース前にバランス調整します。最初から長い時間に設定するとテストが面倒になります。
⭐
レアリティが継続動機を作る
野菜ごとに値段を変えると、プレイヤーが「レアな作物を育てたい！」という目標を持ちます。これが毎日ログインする理由になります。

❌ 初心者がつまずきやすい点

❌ 畑に柵がなくエリアが不明確
✅ 柵で畑と外のエリアをはっきり区切る。あとのシステム設置がずっと楽になります
❌ Radar block が広すぎて遠くでもUIが表示される
✅ Radar block は Shop・畑の入口サイズにぴったり合わせる
❌ テスト時の短い成長時間のまま公開してしまう
✅ リリース前に成長時間を実際のプレイに合った長さに必ず調整する
❌ 茎に ClickDetector を入れ忘れて収穫できない
✅ 茎の Part の中に ClickDetector を追加してからスクリプトを書く
❌ 放置した野菜の自動消滅処理を忘れて畑がいっぱいに
✅ 一定時間後に茎が自動で消えるスクリプトを最初から入れておく

🚀 応用アイデア

💎 レア作物コレクション
低確率でしか育たない「激レア野菜」を追加する。収穫した瞬間に特別なエフェクトと音が出ると、SNSで「出た！」と共有されて口コミが広がります。
🎄 季節イベント限定種
期間限定の種を追加して、毎シーズン新しい目標をプレイヤーに提供する。「今月しか育てられない野菜」がログイン動機を継続させます。
🐄 家畜システムの拡張
家畜小屋から卵が産まれる仕組みを追加する。種の育成と並行して進められる別ゲームループが生まれ、プレイ時間が自然と伸びます。
