🗺️ 全体の流れ

コインゲームは以下の4つの要素で構成されています：

① コインオブジェクト作成  →  ② Touched イベント設定  →  ③ スコア加算  →  ④ 一定時間後に復活

これらをひとつの Script にまとめてコインに貼り付けるのが基本パターンです。

🛠️ 実践ステップ

1 コインパーツを作る

Roblox Studio の Workspace に Part を追加し、コインらしく加工します。

  • Shape を Cylinder に変更（Propertiesウィンドウ）
  • Size を 0.2, 1, 1 くらいに縮小
  • BrickColor を Bright yellow に設定
  • Anchored を ON（固定しないと重力で落ちる！）
  • 名前を Coin に変更
2 leaderstats を作る（スコア保存の準備）

ServerScriptService に Script を追加し、以下を貼り付けます。

-- ServerScriptService → Script local Players = game:GetService("Players") Players.PlayerAdded:Connect(function(player) local leaderstats = Instance.new("Folder") leaderstats.Name = "leaderstats" leaderstats.Parent = player local coins = Instance.new("IntValue") coins.Name = "Coins" coins.Value = 0 coins.Parent = leaderstats end)
  • フォルダ名は必ず leaderstats（大文字小文字も正確に！）
  • これでゲーム画面右上にコイン数が自動表示されます
3 コインに Script を貼り付ける

Coin パーツの中に Script を挿入（右クリック → Insert Object → Script）

-- Coin パーツの中の Script local coin = script.Parent local debounce = false -- 二重カウント防止フラグ coin.Touched:Connect(function(hit) if debounce then return end local character = hit.Parent local humanoid = character:FindFirstChildOfClass("Humanoid") if humanoid then debounce = true coin.Transparency = 1 -- コインを非表示に coin.CanCollide = false -- スコアを加算 local player = game.Players:GetPlayerFromCharacter(character) if player then local leaderstats = player:FindFirstChild("leaderstats") if leaderstats then leaderstats.Coins.Value += 1 end end task.wait(3) -- 3秒後に復活 coin.Transparency = 0 coin.CanCollide = true debounce = false end end)
4 コインをマップに複数配置する
  • Coin を右クリック → Duplicate（Ctrl+D）でコピー
  • 複数のコインを好きな場所に配置
  • コインごとに Script が入るので、それぞれ独立して動作します
  • 見た目をよくしたいときは SpecialMesh で形を変えるのもOK
5 テストプレイで動作確認
  • Studio 上部の Play ボタン（▶）を押してテスト
  • キャラクターをコインに近づける
  • コインが消えて、画面右上のスコアが増えれば成功！
  • 3秒後にコインが復活するか確認

⭐ 重要ポイント

⭐debounce（デバウンス）は必須！

Touched イベントは1回の接触で何十回も発火します。debounce フラグを使わないとコインが1枚で何十枚分もカウントされてしまいます。

⭐Anchored を必ず ON に

コインは空中に浮いていることが多いです。Anchored をOFFにすると重力で地面に落ちてしまいます。

⭐script.Parent でコイン自身を参照

script.Parent はスクリプトが入っているオブジェクト（コイン）を指します。コピーしても自動的に正しいコインを参照します。

⭐CanCollide も一緒に切る

Transparency を1にしても当たり判定が残ります。CanCollide = false にすることで見えない壁が残るバグを防げます。

⭐Server Script を使うこと

スコア管理はサーバー側（Script）で行います。LocalScript で書くとスコアが自分にしか見えなくなります。

❌ 初心者がつまずきやすい点

❌ leaderstats の名前を間違える（LeaderStats、Leaderstats など）
✅ 必ず小文字で leaderstats と書く（Roblox の仕様）
❌ Script を Workspace 直下に置いて coin を名前で探す
✅ Script はコインの中に入れて script.Parent で参照する
❌ debounce なしで書いてスコアが爆発的に増える
✅ local debounce = false を先頭に書いて必ず使う
❌ LocalScript でスコアを変えて自分だけ反映される
✅ スコア変更は必ずサーバー Script（Script）で行う

🚀 応用アイデア

  • コインに価値を付ける — 金・銀・銅のコインを作り、それぞれ加算値を変える（金 = 10点、銀 = 5点、銅 = 1点）
  • タイマーを追加する — 制限時間内に何枚集められるか競うゲームにする
  • 効果音を付ける — Sound オブジェクトをコインに追加して取得時に鳴らす
  • コインが動く — TweenService でコインを回転・上下に動かして見栄えをよくする
  • DataStore でセーブ — サーバー閉鎖後もスコアが残るように DataStoreService を使う

✅ チェックリスト

  • Coin パーツを作り、Anchored をONにした
  • leaderstats フォルダを ServerScriptService の Script に作った
  • コインの中に Script を挿入した
  • debounce フラグを使っている
  • Transparency と CanCollide を両方切っている
  • テストプレイでコインが消えてスコアが増えることを確認した
  • 3秒後にコインが復活することを確認した
  • コインを複数配置してすべて動くか確認した
