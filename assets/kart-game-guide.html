🔧実践ステップ
STEP 1カートモデルの準備（ChatGPT + Blender）

やること
ChatGPTに「Roblox用マリオカート風カートの画像を生成して」と依頼 → 画像をBlenderに読み込んでローポリモデルを作成。

注意点
メッシュはなるべくローポリに仕上げること。テクスチャは512サイズが適切（1024より小さい方がデータ量を抑えられる）。タイヤはBlenderで作らずStudioで追加する。

確認ポイント
カクカクした形を作るときは、角を潰しておくと見た目が良くなる。スムーズシェーディングより平坦な面の方がRobloxらしいデザインに仕上がる。

STEP 2Roblox StudioへのインポートとタイヤのWeld固定

やること
カート本体をインポート → 名前を「カート」に変更 → シリンダーパーツでタイヤを作り、スケールを1.5に調整。

素材設定

  • タイヤ外側：素材「ラバー」、色「ブラック」
  • タイヤ内側：複製してサイズ0.8×0.5に縮小、素材「メタル」、色「グレー」

WeldConstraintの設定
Wキーを押して「WeldConstraint」を選択 → プロパティで「パーツ0」にカート本体、「パーツ1」にタイヤを設定。前後のタイヤも同様に固定し、まとめてモデル化する（右クリック → モデル）。

STEP 3コースの制作（Blender）

やること
参照画像をBlenderに読み込み（Shift+A → 画像 → 参照）、カーブ（Shift+A → カーブ → パス）でコースラインを描く。

コースのパイプ化手順

  • スタートとゴールの2点を選択して Ctrl+C で接続（ループにする）
  • モディファイヤー → カーブ → 解像度を「3」に変更して断面を丸くする
  • 右クリック → 変換 → メッシュ に変換

道路の仕上げ
編集モードで下半分の頂点を削除（X軸基準）→ S+Enter で平坦化 → 3番（面選択）で上面を選択 → Eキーで押し出して厚みをつけ、道路の縁を作る。

STEP 4カートの走行システム（スクリプト方式）

採用方式：スクリプトのみ（最もマリオカートらしい挙動）

① Seatスクリプト（走行制御）

-- 主要な設定値 speed = 80 -- 最高速度（変更でスピード調整） steering = 30 -- ハンドリングの強さ -- AとDキーでハンドリング、RunServiceで滑らか動作

② ServerScript（コースアウト復帰）

-- コースから外れても2秒間は走れる -- 2秒後に「1秒前の位置」へ自動テレポート -- マリオカートのヘリコプター復帰と同じ動作

③ LocalScript（カメラ固定）

X = 0 -- 左右は固定 Y = 8 -- 地面から8上 Z = -12 -- カートの12後ろから追従

確認ポイント
カメラがぐるぐる回らないことを確認。後方固定にすることでハンドリング時の視認性が向上する。

STEP 5スピードブースト矢印の追加

やること

  • テンプレートパーツに矢印テクスチャを貼り付ける
  • Transparency（透明度）を1に設定（ゲーム開始前は非表示、スタートで浮き出る）
  • 10×10の透明ブロックをコースに配置（当たり判定用）

当たり判定ブロックの設定

  • Transparency = 1（透明）
  • CanCollide = OFF
  • CanTouch = ON（これを残すこと）
  • Anchored = ON（落下防止）

スクリプトのポイント
スピード属性（Attribute）を別管理にすること。メインのスピード値と分けておくと、ブーストの数値を個別に調整できる。

STEP 6アイテムボックスの設定

アイテムボックスを6個設置。各ボックスに1つずつスクリプトを付ける（同じスクリプトを全ボックスにコピー）。

アイテム 使い方 効果 持続
🍌 バナナ Eボタンで設置 当たるとカートが3.5回転スピン、その後停止 当たるまで残る
🐢 甲羅（コーラ） Eボタンで投げる 当たると1.5秒後に消滅＋スピン。当たらなくても2秒で消える 最大2秒
🍄 キノコ Eボタンで使用 通常80 → 160まで即時加速 1.5秒

確認ポイント
1列に2個並べると「1個取ったら残りはすり抜ける」仕様が自然に実現できる。消えたボックスは3秒後に自動復活する。

STEP 7ゴーストシステムとラップタイム

スタート台・ゴールラインの設定

  • Transparency = 0.5（半透明）でカートに被さるように配置
  • CanCollide = OFF（すり抜け可能）
  • Anchored = ON（必須！ONにしないと沈む）

ゴーストシステムの仕組み
1周目のラップデータをセーブ → 2周目スタート時にゴーストカーが現れて追いかけてくる → セーブデータが残るので何度プレイしてもゴーストが出現する。

ラップ数の変更
スクリプト内の数値を変えるだけ。5にすれば5周、3にすれば3周のレースに変更できる。音は3種類（アイドリング・走行・ドリフト）をそれぞれ設定すること。

⭐重要ポイント
  • ⭐ スクリプトのみで動かす方式が最もマリオカートらしい挙動になる（シャーシー方式は操作が複雑でNG）
  • ⭐ WeldConstraintは「パーツ0 = カート本体、パーツ1 = タイヤ」の順番が重要
  • ⭐ コースアウト検知は「2秒グレース → 1秒前の位置に戻す」が自然な復帰に見えるポイント
  • ⭐ スピードを上げるときは走行スクリプトの数値（speed/steeringの両方）を合わせて変更する
  • ⭐ アイテムボックスを1列2個並べると「1つしか取れない」ルールが自動的に実現できる
