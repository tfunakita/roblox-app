🗺️ 仕組みの全体像

Roblox のリーダーボードは 自動表示システム です。ルールに従ってフォルダを作るだけで、Roblox が勝手に画面右上に表示してくれます。

PlayerAdded イベント発火  →  leaderstats フォルダ作成  →  値（IntValue等）を子に追加  →  自動で画面に表示

ポイントは「leaderstats という名前のフォルダをプレイヤーの直下に作る」というルールを守るだけです。

🛠️ 実践ステップ

1 ServerScriptService に Script を追加
  • Explorer で ServerScriptService を右クリック
  • Insert Object → Script を選択
  • Script の名前を LeaderboardScript などに変更（任意）
2 基本のリーダーボードを書く
-- ServerScriptService → Script local Players = game:GetService("Players") Players.PlayerAdded:Connect(function(player) -- ① leaderstats フォルダを作る（名前は絶対に変えない！） local leaderstats = Instance.new("Folder") leaderstats.Name = "leaderstats" leaderstats.Parent = player -- ② コイン数の値を追加 local coins = Instance.new("IntValue") coins.Name = "Coins" coins.Value = 0 coins.Parent = leaderstats -- ③ ポイントの値を追加 local points = Instance.new("IntValue") points.Name = "Points" points.Value = 0 points.Parent = leaderstats end)
  • coins.Name の文字列がリーダーボードの列名になる
  • 表示順は追加した順番通り
3 スコアを変化させる

スコアを変えたいときは Value プロパティを操作します。

-- コインを1増やす例 local leaderstats = player:FindFirstChild("leaderstats") if leaderstats then leaderstats.Coins.Value += 1 -- 加算 leaderstats.Points.Value -= 5 -- 減算 end
4 テストプレイで確認
  • Play ボタン（▶）を押す
  • 画面右上に「Coins 0」「Points 0」が表示されれば成功！
  • 表示されない場合は leaderstats のスペルを確認

⭐ 重要ポイント

⭐フォルダ名は必ず leaderstats（小文字）

Roblox エンジンがこの名前を特別に認識します。大文字が混じると表示されません。

⭐PlayerAdded に接続する

ゲームに新しいプレイヤーが入るたびに自動でリーダーボードを作成します。

⭐値は player の子孫でないと反映されない

leaderstats.Parent = player が必須。Workspace 等の別の場所に置いても表示されません。

⭐ServerScript で書く（LocalScript は不可）

LocalScript はクライアント側なので他のプレイヤーのスコアに影響できません。

❌ 初心者がつまずきやすい点

❌ フォルダ名を "LeaderStats" や "Leaderstats" にしてしまう
✅ 必ず全部小文字 leaderstats で書く
❌ Script を StarterPlayerScripts に置いてしまう
✅ リーダーボードのスクリプトは ServerScriptService に置く
❌ ゲーム開始時にすでにいるプレイヤーにリーダーボードが作られない
✅ スクリプトの最後に for _, p in Players:GetPlayers() do ループを追加
❌ leaderstats.Coins.Value = leaderstats.Coins.Value + 1 の書き方で混乱
✅ += 1 の省略形が使えて便利（Lua 5.1 以降）

🚀 応用アイデア

  • DataStore でセーブ — サーバー終了後もスコアが保存されるように DataStoreService を使う
  • レベルシステム — 一定ポイントでレベルアップし、StringValue で称号を変化させる
  • タイムランキング — NumberValue でタイムを記録し、最速タイムを表示する
  • キルデス比 — Kill と Death の IntValue を両方作り比率で順位を付ける

✅ チェックリスト

  • ServerScriptService に Script を追加した
  • leaderstats フォルダを小文字で作った
  • IntValue などの値を leaderstats の子に追加した
  • テストプレイで画面右上にスコアが表示された
  • スコアを変化させる処理を別のスクリプトから呼べた
