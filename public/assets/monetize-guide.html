🎫 GamePass の作り方

📋 Creator Hub での設定手順
  1. Roblox の Creator Hub（create.roblox.com）にアクセス
  2. 対象のゲームを選択 → Monetization → Passes
  3. 「Create a Pass」をクリック
  4. 名前・説明・アイコン画像・価格（Robux）を設定
  5. 保存後、Pass ID をコピーしておく

Studio での実装コード

-- ServerScriptService → Script local MarketplaceService = game:GetService("MarketplaceService") local Players = game:GetService("Players") local VIP_PASS_ID = 123456789 -- 自分のPass IDに変える Players.PlayerAdded:Connect(function(player) -- プレイヤーがGamePassを持っているか確認 local hasPass = MarketplaceService:UserOwnsGamePassAsync( player.UserId, VIP_PASS_ID ) if hasPass then -- VIP特典を付与（例：移動速度2倍） local character = player.Character or player.CharacterAdded:Wait() local humanoid = character:WaitForChild("Humanoid") humanoid.WalkSpeed = 32 -- 通常の2倍 print(player.Name .. " はVIPです！") end end)

🛒 Developer Products（消費アイテム）

📋 Creator Hub での設定手順
  1. Creator Hub → ゲームを選択 → Monetization → Developer Products
  2. 「Create a Developer Product」をクリック
  3. 名前・説明・アイコン・価格を設定して保存
  4. Product ID をコピー
-- ServerScriptService → Script local MarketplaceService = game:GetService("MarketplaceService") local COIN_PRODUCT_ID = 987654321 -- 自分のProduct IDに変える MarketplaceService.ProcessReceipt = function(receiptInfo) local player = game.Players:GetPlayerByUserId(receiptInfo.PlayerId) if not player then return Enum.ProductPurchaseDecision.NotProcessedYet end if receiptInfo.ProductId == COIN_PRODUCT_ID then -- コインを100枚追加 local leaderstats = player:FindFirstChild("leaderstats") if leaderstats then leaderstats.Coins.Value += 100 end end return Enum.ProductPurchaseDecision.PurchaseGranted end

💹 価格設定の考え方

価格（Robux）目安向いているもの
25〜50 R$入門価格（気軽に買える）見た目アイテム、小さなブースト
100〜200 R$標準価格VIPパス、中程度の特典
500〜1000 R$プレミアム価格大きな永続特典、希少アイテム
  • 最初は安めに設定してプレイヤーの反応を見る
  • 「無料で遊べるが課金するとより楽しい」設計が長く続くゲームの秘訣
  • 強すぎる課金要素（Pay to Win）はレビューが下がる原因になる

⭐ 重要ポイント

⭐ProcessReceipt は必ず返り値を返す

PurchaseGranted を返さないと購入処理が完了せず、プレイヤーに二重請求される可能性がある。

⭐GamePass 確認は Server Script で行う

LocalScript で確認するとクライアント側で偽装できる可能性があるため必ずサーバーで確認する。

⭐Roblox の収益還元率は約25〜70%

Developer Exchange（DevEx）で Robux を現金に換えると手数料が引かれる。条件は公式ページで確認。

❌ 初心者がつまずきやすい点

❌ Product ID と Pass ID を間違える
✅ Creator Hub で作ったものの ID を正確にコピーして使う
❌ ProcessReceipt で返り値を忘れる
✅ 必ず return Enum.ProductPurchaseDecision.PurchaseGranted を返す
❌ テスト時に実際に課金してしまう
✅ Studio テスト中はダイアログが出るが実際には請求されない（テスト購入）

✅ チェックリスト

  • Creator Hub で GamePass または Developer Product を作った
  • ID を正確にコピーしてスクリプトに書いた
  • Server Script で所持確認・購入処理を書いた
  • Studio でテストプレイして購入ダイアログが出ることを確認した
  • 特典が正しく付与されることを確認した
